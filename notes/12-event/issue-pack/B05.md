## Work

- Use rules v0.1.1 data and its content hash. Check the old generated JSON header: it still said 0.1.0 despite updated tolerances. Keep the asset and record metadata aligned.
- Implement WITHIN, OUTSIDE, RESCAN, NEEDS_TAPE and NOT_SEEN, plus no-verdict measurement-only mode. Gate missing coverage/card/measurement before numerical comparison; uncertainty touching a boundary is RESCAN.
- Implement the drawing spacing policies mean +max(10 mm,5%) and local +max(15 mm,25%), explicitly labelled proposed project tolerances, not statutory BIS allowances. Distinguish drawing checks from applicable code checks and Zone II advisories. Missing effective depth or other code inputs means not evaluated/needs reading, never invented defaults.
- Produce structured FixAction fields from confirmed requirements and observed counts. The speech/UI cannot recompute numbers or choose the verdict.
- Implement offcut mass helper with editable length, default 200 mm; measured mass/length and tolerances yield a size-class consistency check, not steel grade/authenticity or material certification.
- Return rule ID/version, source, limit, uncertainty, evidence source and advisories for the record and UI.

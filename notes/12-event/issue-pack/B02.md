# Deliver a verified rebar model and prove its on-phone runtime

The live pipeline receives correct bar probabilities, with an honest accelerator label and a working fallback.

Work against B01 fixtures while a service dependency is being built; acceptance still needs the real service. The control issue defines the explicit manual/gated fallback path. Do not close an unproven automatic feature just because the fallback shipped.

## Ownership and deliverable

Own **segment/, model assets and MODEL_CARD inputs**. You are not alone in the codebase: preserve others' changes. Alwin owns UI, Sabari camera/geometry, Melvin shared types/build/rules/trust. Request a handoff before editing another package or frozen contract.

## Work

- Start artifact inventory immediately, in parallel with B01: find actual trained/exported files, training log, licence, dataset provenance and checksums. A training script or Kaggle job is not a shipped model.
- Document the actual tensor contract. The current export design is RGB NHWC float32 [1,640,1152,3] in 0..255, ImageNet normalization inside the graph, sigmoid probabilities [1,640,1152,1]. Inspect the artifact rather than assuming it matches.
- Run the identical saved prop frame through laptop and Android preprocessing/inference; preserve rotation, resize and padding metadata for inverse mapping. Do not feed the Y plane to an RGB-trained graph or normalize twice.
- Run 50 warm iterations per available backend, separate initialization/preprocess/inference/postprocess times, record backend evidence and partial delegation. A requested NPU backend alone is not proof of execution there.
- Prove the sideloaded APK includes the model and required native runtime offline. A Play-delivered example does not establish sideload delivery. Linux export/AOT may be needed; keep a portable float model.
- Timebox NPU repairs to 45 minutes total, then GPU/CPU as measured. Generic DeepLab segmentation is not a rebar fallback without a trained bar head. Inform Alwin early if B07 manual topology is needed.

## Acceptance

- [ ] Model checksum and tensor shape/type/range are captured. Missing/corrupt assets produce an actionable state rather than a crash.
- [ ] Same-image probability/mask comparison is saved; target thresholded mask IoU >=0.90 between laptop and phone on representative prop frames, with justified quantization differences recorded.
- [ ] Rotation tests preserve alignment. Actual runtime backend and p50/p95 appear in telemetry; unsupported backends show unavailable, not fabricated timings.

**Loaner check:** Run CONTROL and F2 saved images, then the real prop; inspect thin bars, the two close bars in F2, and the backend chip with network disabled.

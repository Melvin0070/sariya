## Ownership and deliverable

Own **ui/scan/ renderer and manual-mark editor**. You are not alone in the codebase: preserve others' changes. Alwin owns UI, Sabari camera/geometry, Melvin shared types/build/rules/trust. Request a handoff before editing another package or frozen contract.

## Work

- Consume fake LiveFrameResult/LockResult first so development does not wait on B06/B08. Render lines/labels using the provided transforms and timestamp; stable slot labels must not jump between families.
- Use a visible tilde/live state before Lock, progress during Lock, then a frozen image and exact band/result after Lock. Lost card, moved bar or changed spec visibly invalidates fresh measurement; preserve old saved scans as historical only.
- Build tap-to-mark now, before CP1: freeze a valid calibrated frame, let the user mark/refine bar centrelines, feed the same geometry/rule contracts, and keep `marked by hand` provenance in UI and records.
- Manual marking must not bypass card, coverage, calibration or uncertainty gates. Count can come from human topology, but the app must not claim automatic detection.
- Make retry/cancel/repeat speech and next scan obvious. Show re-scan reason as text and action, not colour alone.
- Own a minimal tape ground-truth entry panel now: select locked gap/family, enter tape c/c and operator/source, write a bench row via the B08/B01 contract. This must exist before the later numbers-screen polish.

## Acceptance

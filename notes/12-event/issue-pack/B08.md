# Lock measurements with honest uncertainty and pass the tape gate

A Lock produces repeatable count/spacing, evidence and an error band that survives contact with a tape.

## Work

- Collect about 15 valid, temporally consistent frames while gyro and scene are stable. Reject changing topology, moving bars, spec changes, stale timestamps and insufficient coverage; camera stillness alone does not prove the bars stayed still.
- Fuse matched bar positions robustly in card mm. Do not divide systematic calibration, plane-offset or scale errors by sqrt(frame count); temporal correlation does not create independent samples.
- Start with field floor 5 mm and all applicable geometry terms. Record lock ID, sample count, frames/time range, uncertainty terms, effective stream/calibration, model hash, evidence image hashes and manual/automatic source.
- Select an evidence frame from the accepted lock window and draw measurements on it. If high-resolution still is the measurement fallback, recompute on that actual frame with its own calibration; never sign a later photo as if it generated the fused values.
- Run the gate on tape-labelled props: 10 CONTROL scans for count/spacing plus F1/F2/far card; reserve separate observations for calibration and evaluation. Log failed/re-scan attempts too.
- Freeze immutable LockResult before calling rules. Never pool different families, streams, manual and automatic methods or model versions into one accuracy claim.

## Acceptance

- [ ] G1: CONTROL count 5/5 in 10/10 accepted test scans and tape spacing inside its band on at least 8/10 attempts; also report abstentions and denominator. This is a bench gate, not a field accuracy claim.
- [ ] F2 count remains five and 80 mm is outside only if the measured band permits; F1 misses a bar; the far card abstains. F4 72 only counts as outside if lower bound exceeds 65.
- [ ] Synthetic tests cover 15 identical correlated frames, changed spec, moving bar, dropped frame, missing card and evidence mismatch; none shrinks systematic uncertainty or produces stale LockResult.
- [ ] G1 additionally requires band <15 mm on F2 and zero false WITHIN outcomes on the tested missing-bar/wide-gap fixtures. Report numeric error and band distribution alongside coverage. A huge band cannot pass useful fault discrimination; no artificial band cap is applied to measurements. F4 outside is optional and needs band <7 mm.

**Loaner check:** Tape the exact drawn centre-to-centre segment at 0.25/0.30/0.35 m; capture near and far failed attempts in the bench ledger.
